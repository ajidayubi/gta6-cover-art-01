Vice Cover Maker turns your own photos and a caption into a striking multi-panel poster cover, with sunset and neon colour grades, and exports it as a PNG in 1080 x 1080, 1080 x 1350, or 1920 x 1080. It runs fully offline in a desktop browser; your photos never leave your machine.

## Run it

Serve the app and open http://localhost:8080:

```
node serve.ts
```

Build the submission dossier:

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
